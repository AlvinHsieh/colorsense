# Privacy

## v0.1 data policy

ColorSense does not collect, transmit, sell, or retain browsing data. It has no server, analytics,
telemetry, account, advertising SDK, or external API.

The extension may execute a minimal isolated probe in the active tab after the user opens the
extension. The probe returns only a generated request identifier, response type, source, and local
extension version. It does not read or return page content.

## Prohibited data

- Form and input values.
- Passwords, authentication tokens, cookies, or credentials.
- Full DOM, screenshots, or page source.
- Browsing history or cross-site activity.
- Personal or confidential information.

Any future requirement to process additional page information must update the threat model, explain
retention and data flow, use the minimum browser permission, and receive explicit maintainer review.
