# Support

ColorSense is an early open-source project.

- Reproducible defects: open a **Bug report** Issue.
- Product proposals: open a **Feature request** Issue.
- Real color-accessibility barriers: open an **Accessibility case** Issue after removing personal or
  confidential page content.
- Security vulnerabilities: follow [SECURITY.md](SECURITY.md) privately.

Support does not cover private-site debugging that requires credentials, medical diagnosis, color
vision certification, or guarantees that every web interface can be interpreted correctly.
